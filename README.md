# X Autopilot

Starter X automation dashboard using Gemini for generation and the official X API for publishing.

## Setup

1. Copy `.env.example` to `.env.local`.
2. Add your Gemini API key.
3. Add your X access token.
4. Run `npm install`.
5. Run `npm run dev`.

The first version intentionally requires you to review the generated post before publishing.

## Important

Use official X API access and comply with X's automation/developer rules. Do not use browser automation to bypass API restrictions.
